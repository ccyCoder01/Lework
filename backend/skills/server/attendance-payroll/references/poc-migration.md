# 原型能力迁移说明

本 Skill 从内部原型迁移而来。核心能力对应关系：

- 工资基准快照和历史工资解析
- 人员底表解析
- 确定性工资计算与公式说明
- 考勤视觉识别 JSON 结构
- 五个 Excel Sheet 的导出结构

不要迁移原型的浏览器 IndexedDB、客户端 PDF 预处理 UI、边缘 Worker 或演示页面。Lework 中应将基准和中间产物写入当前项目/任务工作区，识别与计算过程保留来源证据，并使用现有 worker 的文件、模型和 artifact 能力。

原型的部分核算行为优先于过时设计文档：缺少单个人员基准时允许其他人员继续计算并列出缺失清单；规则不明确的分项必须进入人工复核。
